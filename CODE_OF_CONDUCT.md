# Code de conduite

## Notre engagement

Nous nous engageons à offrir un environnement de collaboration respectueux, bienveillant et sans harcèlement, quels que soient l'âge, le genre, l'origine, le niveau d'expérience, le handicap ou les opinions de chacun.

## Comportements attendus

- Être respectueux et constructif dans les échanges
- Accepter les critiques sur le travail sans les prendre pour des attaques personnelles
- Faire des retours précis et bienveillants en review
- Reconnaître le travail des autres

## Comportements inacceptables

- Insultes, moqueries, attaques personnelles
- Harcèlement, discrimination, propos haineux
- Publication d'informations privées sans accord
- Tout comportement qui serait déplacé dans un cadre professionnel

## Application

Les mainteneurs peuvent modifier ou supprimer tout commentaire, commit ou contribution qui ne respecte pas ce code, et écarter temporairement ou définitivement un contributeur.

## Signalement

Pour signaler un comportement inacceptable, contacter le mainteneur du dépôt via son profil GitHub : https://github.com/leolesimple

Ce code de conduite est adapté du [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/), version 2.1.
